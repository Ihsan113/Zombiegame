# Implementation notes — v0.4.1

- `ARENA_TOP_RATIO=0.565` and `ARENA_BOTTOM_RATIO=0.865`. Movement/loaded positions clamp sprite centers +/-40 px inside that lane so the animated sprite stays within both edges; spawns get an extra 10 px safety margin.
- Each wave starts with `max(55, 90 - 3 * (wave_number - 1))` seconds. The clock stops during intermission. On expiry, `wave_timed_out` displays OVERTIME and zombie walking speed is multiplied by 1.18; the wave still ends only after its full enemy count is spawned and all zombies are killed.
- `game_over` is asserted when no player remains above 0 HP. Host broadcasts reliable Game Over state; subsequent world snapshots include wave timer/overtime/game-over flags. Restart resets all zombie/effect arrays, all player vitals and spawn positions, cooldowns and wave state, then tells LAN clients to resume.
- Runtime cleanup is centralized in `_reset_network_state` and `_leave_world`; exit is no longer an implicit save. New Solo and Create World run clean; `Continue Saved` explicitly invokes `_load_world`. Manual Save is retained.
- Eight mono 22,050 Hz 16-bit WAV effects are original synthesized assets under `assets/audio`: `shot`, `hit`, `attack`, `death`, `heal`, `wave_start`, `wave_clear`, `game_over`. They load through `AudioStreamPlayer`; hosts relay event keys to LAN clients. No external sound asset license is required.
- CI validates every `res://` reference, landscape orientation, script markers, WAV format/presence, Godot import/compiler output, a headless scene start and Android export. Only an actual Godot CI run/device test can confirm runtime behavior.
